# 铁路信号联锁测试用例编排与回归记录平台

源提示词编号：14。包含道岔、信号机、轨道区段与进路关系，Canvas 站场缩放与定位，受设备变化影响的回归范围推导，用例步骤/预期/依赖编排，实时执行同步、断线重试、失败证据、基线锁定和测试报告导出。

## 天窗动态排程（新增）

「天窗动态排程」把**步骤依赖、设备按小时段独占、班组资格、发布检查**接成动态重算：

- **步骤依赖**：有向无环图拓扑排程，前置排不进去时后续按「依赖无法满足」列出；
- **设备独占**：道岔 / 轨道区段 / 信号机按整点小时段占用，同设备同时段冲突报「设备重叠」，超出天窗报「窗口容量不足」；
- **班组资格**：班组须持有对应设备类型资质且等级达标，资格独立判定（不被前置失败掩盖），不符者集中列出；
- **时长更新即失效重算**：变更步骤钉住原起始时段向右延长，当前天窗内传递后继的时间锚点失效重排，无依赖、无设备争用的步骤锚点不动；
- **已下发窗口冻结**：下发后按计划号只读，任何后续变化不回改；
- **越权拒绝**：只有承接班组的班组长可调整该班组的步骤时长/班组，他人操作拒绝并写审计日志；
- **写入失败保留可执行版本**：下发失败保留窗口草稿，按同一计划号幂等重试（页面上有「模拟下一次写入失败」开关）；
- **旧数据升级**：缺班组编号的旧台账步骤，按设备类型 + 等级要求补齐到旧来源工班并留痕。

行为校验：`npm run check:schedule`（32 项引擎/存储流程断言）。
